# Resume Analyzer

## Description
AI-powered Resume Analyzer built with Python and Flask.  
It extracts skills, experience, and education from uploaded resumes and provides a job match score.

## Features
- Upload PDF/Word resumes
- Extract skills, experience, and education
- Score resumes based on job description
- Suggest relevant jobs

## Tech Stack
- Python
- Flask
- pandas, spaCy, PyPDF2
- HTML/CSS (templates + static)
